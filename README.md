# Сквош · сетка и судейство

Бот-помощник для групповых игр в сквош: строит расписание, ведёт таблицу и даёт судейскую
консоль. Один файл `index.html`, без сборки, зависимостей и сервера — работает офлайн в браузере,
подходит для GitHub Pages.

**Связь и обратная связь:** ошибки, вопросы, идеи — Telegram [@sailofsoul](https://t.me/sailofsoul).
Исходники: GitHub (адрес укажите в `REPO_URL` в начале `index.html`).

## Быстрый старт

1. Добавьте игроков (2–12) или нажмите «Пример (12)».
2. Выберите корты (1–3), формат, длительность матча и время начала.
3. Нажмите «Построить сетку» (дальше кнопка станет «Пересобрать сетку» и спросит подтверждение).
4. Счёт вводите во вкладке **«Судья»**: выберите свой корт, жмите «−/+», ведите подачу.
5. Таблица и экспорт — во вкладках **«Таблица»** и **«Поделиться»**.

## Форматы

- **Каждый с каждым** — все пары играют ровно один раз; время вычисляется само
  (для 12 игроков и 3 кортов это 66 матчей, 22 записи, 11 часов).
- **По времени** — вы задаёте, сколько играете («Играем, ч»), приложение считает, сколько матчей
  влезет (за 2 часа — 12 матчей, по 2 игры каждому). Оба формата выравнивают число игр на
  человека и не повторяют соперников, пока есть свежие пары.

## Что умеет

- **Сетка:** одиночные матчи 1 на 1, все корты одновременно, отдых чередуется; для 3 кортов
  порядок матчей подобран так, что пауз «две записи подряд» — минимум возможного.
- **Счёт по правилам:** партия до 11, при 10:10 и далее — разница в 2 очка; в таблицу матч
  попадает только после победы. Досрочное завершение (травма, неявка, поведение) присваивает
  победу выбранному игроку.
- **Подача по правилам (PAR):** жребий определяет первого подающего; взял очко — берёшь подачу.
  Когда подача переходит, **квадрат выбирает сам подающий** (лево/право), а пока он берёт очки —
  квадрат чередуется по его счёту. Подача видна всем судьям.
- **Судейские решения:** Let (переигровка), No let (отказ), Stroke (очко тому, кому помешали),
  предупреждение за поведение; **история очков** по каждому матчу со счётом на момент события.
- **Статус «в эфире»:** идущие матчи помечены красным, в сводке видно, сколько идёт сейчас.
- **Правка расписания:** матч можно перетащить на другую запись (за ⠿) или сдвинуть кнопками
  «↑ раньше» / «↓ позже»; кнопка «Кто следующий?» предлагает пару на освободившийся корт так,
  чтобы не было игр подряд.
- **Таблица:** И, В, Пр, забитые, пропущенные, разница и прогресс. В **соревновательном режиме**
  места считаются по победам, затем по разнице очков.
- **Общая комната:** несколько судей видят одну сетку и вносят счёт; роли — организатор, судья,
  зритель. Плюс экспорт/импорт файла и печать сетки.

## Публикация и обновление на GitHub

Первый раз:

```bash
cd "/путь/к/папке/проекта"
git init -b main && git add -A && git commit -m "Сетка и судейство для сквоша"
git remote add origin https://github.com/ЛОГИН/ИМЯ-РЕПОЗИТОРИЯ.git
git push -u origin main
```

Pages: **Settings → Pages → Deploy from a branch → main / (root)**. Адрес будет
`https://ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Обновление после правок — три команды:

```bash
git add -A && git commit -m "что изменил" && git push
```

Пароль от GitHub не подойдёт — нужен личный токен (Settings → Developer settings →
Personal access tokens, права `repo`).

## Общий режим: что важно знать

- Данные комнаты **публичны**: кто знает код, тот их видит. Не вводите персональные данные.
- Обмен идёт через публичный `ntfy.sh` без ключей. Ограничения сервиса: **250 сообщений в сутки**
  и до 4 КБ на сообщение. Приложение экономит (одно сообщение на матч, приём потоком), но для
  регулярных турниров лучше указать свой ntfy-сервер в «Настройках сервера обмена».
- Правки без связи не теряются: копятся и уходят, когда связь вернётся.
- Без комнаты приложение работает полностью локально, данные хранятся в браузере.

## Технически

Один файл `index.html` (HTML + CSS + JS, без зависимостей), состояние — в `localStorage`.
Данные комнаты передаются сообщениями через ntfy (SSE + пакетная отправка). Печать — кнопка
«Печать» в разделе «Поделиться».
