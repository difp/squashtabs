# Сквош · сетка групповых игр

Простое приложение для построения игровой сетки по сквошу: одиночные матчи **1 на 1**,
как на турнирах. Всё в одном файле `index.html` — без сборки, зависимостей и бэкенда.

## Возможности

- До **12 игроков** и до **3 кортов** одновременно.
- Каждый раунд формируется автоматически: 2 игрока на корт, остальные отдыхают.
- Сетка чередует соперников и отдых, чтобы игры были равномерными.
- Ввод счёта по каждому матчу и автоматическая **таблица** (игры, победы, поражения, очки).
- Кнопки **Скопировать** (текстом) и **Печать** (чистый вид без интерфейса).
- Всё сохраняется в браузере (localStorage) — можно закрыть страницу и вернуться.

## Как пользоваться

1. Добавьте игроков (от 2 до 12) или нажмите «Пример (12)».
2. Выберите число кортов (1–3) и количество раундов.
3. Нажмите «Построить сетку».
4. По ходу игры вводите счёт — таблица пересчитывается сама.

## Публикация на GitHub Pages

1. Загрузите `index.html` в репозиторий на GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` и папку `/ (root)`
4. Сохраните. Через минуту страница будет доступна по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Сборка не нужна — GitHub отдаёт `index.html` как есть.

## Локальный запуск

Откройте `index.html` двойным кликом в браузере. Либо поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```
