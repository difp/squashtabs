# Сквош · сетка и судейство

**Расписание, счёт и таблица для групповых игр в сквош** — один файл, без установки и зависимостей, работает офлайн в браузере. До 12 игроков и 3 кортов.
</div>

<img src="docs/screen-grid.png" alt="Сетка игр" width="100%">

Список игроков → «Построить сетку» → счёт во вкладке **«Судья»** → итоги в **«Таблице»**. Для совместной работы — **«Поделиться»** → создать комнату → раздать QR.

**Сетка** — «каждый с каждым» (все пары ровно раз) или «по времени», отдых чередуется, идущие матчи помечены «в эфире». **Счёт** — партия до 11, при 10:10 разница в 2 очка.

**Подача** — взял очко, берёшь подачу; квадрат выбирает сам подающий. **Судейство** — `Let` / `No let` / `Stroke`, предупреждения, история очков, досрочное завершение (травма, неявка).

<img src="docs/judge.gif" alt="Судейская консоль" width="100%">

**Расписание** — матч переносится перетаскиванием, есть подсказка «кто следующий» без игр подряд. **Состав** — вставьте список игроков прямо из сообщения; замена по ходу турнира оставляет сыгранные матчи за выбывшим.

**Таблица** — победы, забитые и пропущенные очки, разница, соревновательный режим. **Несколько судей** — одна сетка на всех устройствах по коду комнаты или QR-коду.

Данные комнаты видны тем, кто знает код, — не вводите персональные данные. Без комнаты всё хранится только в браузере. Ошибки и идеи — issue в этом репозитории.
