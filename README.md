Список игроков → **«Построить сетку»** → счёт во вкладке **«Судья»** → итоги в **«Таблице»**; для нескольких судей — **«Поделиться»**.

## Что умеет

| | |
|---|---|
| 🗓 **Сетка** | «каждый с каждым» или «по времени», отдых чередуется |
| 🎯 **Счёт** | партия до 11, при 10:10 — разница в 2 очка; подача переходит с очком |
| ⚖️ **Судейство** | `Let` / `No let` / `Stroke`, предупреждения, история очков |
| ⏱ **Таймер** | сигнал за минуту до конца и звонок на финише: готовый звук или свой |
| 🔀 **Перенос** | матч переносится на другой корт перетаскиванием или кнопкой «⇄» |
| 👥 **Состав** | список игроков вставляется из сообщения; замена по ходу турнира |
| 📊 **Таблица** | победы, забитые и пропущенные очки, разница, соревновательный режим |
| 🏆 **Плей-офф** | сетка навылет на 4, 8 или 16 — от 1/8 финала: по таблице или жребием |
| 🖨 **Печать A4** | расписание списком, таблица с подписью судьи и сетка навылет |
| 📡 **Судьи** | одна сетка на всех устройствах по коду комнаты или QR |
